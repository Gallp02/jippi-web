# jippi-web

Landing page responsiva para **J & R Inversiones JIPPI**, empresa dedicada a la venta de partes de manufactura: tornillos, pernos, tuercas, tubos, abrazaderas y accesorios.

## Contenido

- Hero con propuesta de valor y llamadas a acción por WhatsApp.
- Catálogo visual por categorías con imágenes locales.
- Secciones de servicios, ventajas, contacto y preguntas frecuentes.
- Páginas de privacidad y reclamaciones.
- Metadatos Open Graph y Twitter Card.

## Stack

- HTML5
- CSS embebido con variables, animaciones y media queries
- JavaScript vanilla para interacciones
- Sin dependencias de build

## Ver en vivo

https://gallp02.github.io/jippi-web/

## Ejecutar localmente

```bash
git clone https://github.com/Gallp02/jippi-web.git
cd jippi-web
python -m http.server 8000
```

Luego abre `http://localhost:8000`.
